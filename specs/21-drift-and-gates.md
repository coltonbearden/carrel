## Why
`docs/REFERENCE.md` is a hand snapshot of `--help` from v0.1.0. `STATE.md` still says "Next: cut v0.1.2". Nine cookbook recipes and eight snippets are invisible on the docs site. CI runs on Linux only and has no coverage floor. `HANDOFF.md` sits untracked at the repo root.

## `scripts/sync_reference.py`
- Walks `carrel.cli.COMMANDS` in sorted order; for each command (and recursively each subcommand of a click group) captures `--help` in-process via `click.Context` / `CliRunner` with `COLUMNS=100`, and writes `docs/REFERENCE.md`: header ("Generated from `--help` of carrel <version> by scripts/sync_reference.py — do not edit"), the global options block, then one `##` section per command with `###` subsections per subcommand, each holding the fenced help text. Exit codes table appended from `core/output.py`'s `ExitCode` docstrings/comments.
- `--check` mode exits 1 when the file would change. `tests/test_reference_sync.py` runs `--check`. The CI lint job runs it and `git diff --exit-code -- docs/REFERENCE.md` alongside the existing `sync_product.py` step.
- Deterministic output (no timestamps; version comes from `_product.py`).
